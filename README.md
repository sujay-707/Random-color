# Random Color Generator

A simple and interactive Random Color Generator built using HTML, CSS, and JavaScript.

Click the **Generate Color** button to generate a random RGB color. The generated RGB value is displayed on the page, and the color preview updates instantly.

## Live Demo

[https://gen-color.netlify.app/](https://gen-color.netlify.app/)

## Features

- Generates random RGB colors
- Generates RGB values from `0` to `255`
- Displays the generated RGB value
- Dynamically changes the color preview
- Responsive and mobile-friendly design
- Lightweight and simple
- Built using vanilla JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

When the **Generate Color** button is clicked:

1. A random value is generated for Red.
2. A random value is generated for Green.
3. A random value is generated for Blue.
4. The three values are combined into an RGB color.
5. The RGB value is displayed on the page.
6. The preview box background is updated with the generated color.
